# Padrões de hardware

> **Situação:** Confirmado (necessidade); Proposto (procedimento). 

As discussões citaram a necessidade de permitir reconstrução de placas a partir de manuais e arquivos EasyEDA, usando uma estação de terra como exemplo. O controle técnico deve associar esquema, PCB, BOM, fabricação, montagem e ensaios à **mesma revisão identificada**. Ver `controle-de-revisoes.md` e `testes-e-validacao.md`.
