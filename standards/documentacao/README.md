# Padrões de documentação

> **Situação:** Proposto. 

Priorize Markdown UTF-8, links relativos e nomes de arquivo legíveis e estáveis. Inclua título, situação, propósito, passos e referências. Em documentação de processo, diferencie **confirmado** de **proposto**; em procedimento técnico, forneça versão, pré-requisitos, execução, validação e recuperação de falhas.
