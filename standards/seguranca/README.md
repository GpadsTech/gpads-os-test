# Segurança da informação

> **Situação:** Proposto. 

Princípios iniciais: menor privilégio, credenciais fora de Git, dados pessoais mínimos, histórico de concessão de acesso, backups e revisão de permissões. As políticas finais devem observar exigências institucionais e legislação aplicável; o documento não é parecer jurídico nem política oficial aprovada.
