# DoD geral — proposta

> **Situação:** Proposto. 

- [ ] Identificador, escopo, responsável e versão definidos.
- [ ] Critérios de aceitação associados ao resultado e testados.
- [ ] Evidências suficientes e localizáveis.
- [ ] Documentação para entender ou reproduzir a entrega.
- [ ] Revisão realizada, com parecer e responsável.
- [ ] Validação realizada, com parecer e responsável.
- [ ] Dependências e limitações registradas.
- [ ] Segurança, licenças e tratamento de dados avaliados quando aplicável.

Uma caixa marcada deve ter link para evidência. Condição dispensada exige motivo e autoridade para dispensa, a definir.
