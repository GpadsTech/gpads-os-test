# Definition of Done por tipo de entrega

> **Situação:** Confirmado (necessidade); Proposto (checklists). 

**Definição:** conjunto mínimo de condições compartilhadas para considerar o trabalho concluído. Os critérios de aceitação medem resultado específico; a DoD verifica qualidade e rastreabilidade da entrega.

- `dod-geral.md`: base aplicável a todas as entregas.
- `dod-software.md`, `dod-hardware.md`, `dod-dados-ia.md`, `dod-pesquisa.md`, `dod-documentacao.md`: exigências adicionais por domínio.

Todos os checklists são **minutas** até homologação. O validador deve indicar quais condições foram aplicáveis e apresentar evidências.
