# Metadados de datasets

> **Situação:** Proposto. 

Campos sugeridos: ID, título, objetivo, responsável, fonte, data de coleta, cobertura temporal/espacial quando pertinente, formatos, unidades, esquema, valores ausentes, qualidade, revisão, licença, restrições de acesso e versão. Dados ambientais exigem também descrição do método de coleta e calibração quando aplicável.
