# Proveniência de dados

> **Situação:** Proposto. 

Uma transformação reprodutível deve permitir reconstruir, com permissão apropriada, qual dado de entrada, script, parâmetro, versão e data gerou um derivado. Registre origem, hashes se disponíveis, controles de qualidade e perdas. Não mova dados restritos para repositório público apenas para cumprir rastreabilidade.
