# Workflow: solicitações

> **Situação:** Proposto. 

Fluxos propostos para pedidos internos, intercelulares, de compra e de aprovação. A existência desta documentação não significa que a plataforma já ofereça formulários para todos os casos. Registre identificador, solicitante, destinatário, objeto, razão, prazo desejado, estado e resultado.
