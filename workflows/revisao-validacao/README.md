# Workflow: revisão e validação

> **Situação:** Confirmado (necessidade); Proposto (procedimento). 

O GPADS-OS deve prever revisão e validação antes da conclusão. O conjunto define submissão, análise técnica, aceite do resultado, devolução e aprovação final. Verifique a DoD apropriada em [`standards/definition-of-done`](../../standards/definition-of-done/README.md).
