# Modelos de trabalho

> **Situação:** Modelo. 

Modelos reutilizáveis: produto, épico, história, microentrega, revisão, solicitação, decisão (ADR), relatório quinzenal individual e consolidado. Copie o conteúdo para um arquivo de instância e substitua campos `[ENTRE COLCHETES]`; não mantenha exemplos como evidências reais. Para relatórios, siga os caminhos definidos em [`docs/05-processos-operacionais/relatorios-quinzenais.md`](../docs/05-processos-operacionais/relatorios-quinzenais.md).
