# Produtos e entregáveis

> **Situação:** Confirmado (hierarquia); Proposto (armazenamento). 

Este diretório oferece catálogo e modelo para documentar os produtos do GPADS. A hierarquia definida é **produto/entregável → épico → história → microentrega**; cada nível deve ser rastreável às evidências e ao responsável.

Para iniciar um produto, copie `_template-produto/` para `products/<slug-do-produto>/` ou mantenha o produto em repositório especializado e registre referência aqui. A decisão por modelo híbrido é **proposta**, não decisão institucional ratificada. Consulte o [`guia de hierarquia`](../docs/04-gestao-de-produtos/hierarquia-de-trabalho.md).
