## Como usar esta célula

Consulte [`integrantes.md`](integrantes.md) para a lista verificada e [`responsabilidades.md`](responsabilidades.md) para a distribuição funcional proposta. Arquive relatos individuais em `membros/<pessoa>/relatorios-quinzenais/<ano>/` e o consolidado em `relatorios/consolidado-quinzenal/<ano>/`. O planejamento é elaborado em `planejamento/`; reuniões em `reunioes/atas/`; solicitações intercelulares seguem [`docs/03-governanca`](../../docs/03-governanca/README.md).
