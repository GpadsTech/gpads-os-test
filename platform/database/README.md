# Banco de dados — diretrizes

> **Situação:** Proposto. 

Mantenha unicidade de pessoas por ID, vínculos históricos por célula, IDs estáveis de entrega e trilhas de auditoria. O cadastro deve permitir que a mesma pessoa participe de várias células sem duplicar sua identidade global.

A modelagem definitiva depende do banco e esquema reais da aplicação. Consulte [`esquema-logico.md`](esquema-logico.md).
