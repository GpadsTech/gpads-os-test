# Integração com GitHub — proposta

> **Situação:** Proposto. 

**Objetivo:** permitir relacionar histórias e microentregas a issues, commits, pull requests, versões e documentação técnica.

Campos de vínculo sugeridos: repositório, item, branch/tag/commit, URL de evidência, resultado de revisão. Política de segurança: token de serviço com mínimo escopo, sem segredos no repositório. **PENDENTE:** organização e nomes dos repositórios efetivos, permissões e meios de integração.
