# Glossário GPADS-OS

> **Situação:** Confirmado (conceitos centrais); Proposto (formulações). 

| Termo | Definição operacional |
|---|---|
| Célula | Unidade de trabalho identificada por missão, membros e interfaces. |
| Membro | Pessoa com vínculo de participação em uma ou mais células. |
| Líder de célula | Integrante expressamente designado para papel de liderança. |
| Produto/entregável | Resultado identificável cujo valor e aceite podem ser avaliados. |
| Épico | Bloco maior de capacidade/resultado, relacionado a produto. |
| História | Necessidade testável com critérios de aceitação. |
| Microentrega | Menor unidade planejável, executável e verificável associada a história. |
| Backlog | Conjunto de demandas ainda não comprometidas para execução. |
| Critério de aceitação | Condição verificável específica de um item. |
| Definition of Done (DoD) | Conjunto de condições mínimas gerais de qualidade e conclusão. |
| Revisão | Análise técnica/documental registrada de uma entrega. |
| Validação | Confirmação registrada de que o resultado atende à necessidade e aos critérios. |
| Evidência | Registro ou artefato que suporta uma afirmação sobre entrega, teste ou decisão. |
| ADR | Registro de decisão arquitetural, alternativas e consequências. |
| Relatório quinzenal | Reflexão factual individual por célula e quinzena, com links de evidência. |
| Consolidado quinzenal | Síntese das atividades, entregas e impedimentos da célula por período. |
| Solicitação intercelular | Pedido rastreável entre células com resultado e responsável. |

**Observação:** os conceitos de quatro níveis de trabalho e DoD explícita foram discutidos no projeto; as definições detalhadas são padronizações propostas.
