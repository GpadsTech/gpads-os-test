# Base de conhecimento do GPADS

> **Situação:** Confirmado (necessidade); Proposto (organização). 

Central de conhecimento reutilizável: manuais (`manuais/`), tutoriais (`tutoriais/`), referências (`referencias/`) e glossário (`glossario/`). Cada material deve ter propósito, pré-requisitos, versão, fonte, execução e critérios de verificação. Referencie arquivos técnicos versionados no repositório de origem em vez de armazenar cópias descontroladas.
