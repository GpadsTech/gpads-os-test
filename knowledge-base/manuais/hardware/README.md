# Manuais de hardware

> **Situação:** Confirmado (exemplo); Proposto (formato).

No exemplo de estação de terra citado nas conversas, os arquivos reais de EasyEDA **não foram disponibilizados neste pacote**. Não inventar revisões de placa.
