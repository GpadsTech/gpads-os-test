# Manuais técnicos

> **Situação:** Confirmado (necessidade); Proposto (padrão). 

Um manual deve permitir a **reprodução de uma atividade** por membro capacitado sem depender de instrução oral. Campos esperados: finalidade, público-alvo, pré-requisitos, materiais, versões, fonte dos arquivos, etapas, resultado esperado, testes, falhas comuns, riscos e responsáveis pela manutenção.

Para um projeto eletrônico exemplificativo, registrar como localizar esquema e PCB EasyEDA, BOM, revisão da placa e testes. **Nenhum manual de placa real está incluído neste pacote.**
