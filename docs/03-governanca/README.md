# Governança do GPADS-OS

> **Situação:** Confirmado (questões); Proposto (soluções). 

Esta seção responde, como **minutas de processo**, às questões levantadas no gpadsLab: como enviar demandas entre células, como solicitar compras, onde armazenar instruções, quem aprova e como localizar decisões. Arquivos aqui não constituem políticas institucionais do IFPE sem ratificação.

Consulte `modelo-de-governanca.md`, `matriz-de-responsabilidades.md`, `direitos-de-decisao.md`, `gestao-de-solicitacoes.md`, `comunicacao-interna.md`, `gestao-de-compras.md`, `gestao-de-conflitos.md` e `politica-de-acessos.md`.
