# Matriz de responsabilidades — esboço

> **Situação:** Proposto. 

RACI de referência (**R** executa, **A** responde pela aprovação, **C** consulta, **I** informado). Atribuições abaixo são **papéis a designar**, não nomes de pessoas.

| Atividade | Executor | Líder da célula | Revisor/validador | Instância administrativa |
|---|---|---|---|---|
| Executar microentrega | R | C | C | I, se aplicável |
| Planejar atividades da célula | C | R (A a confirmar) | C | I |
| Revisar artefato | C | C | R (A a confirmar) | I, se aplicável |
| Solicitar compra | R (solicita) | C | C, se técnico | A conforme regra institucional |
| Alterar política de governança | C | C | C | A conforme competência formal |

Os campos de **A** não deverão ser interpretados como delegação de autoridade sem decisão formal.
