# Direitos de decisão — proposta

> **Situação:** Proposto. 

Decisões devem indicar: assunto, escopo, impacto, instância competente, responsáveis consultados, decisão, fundamento, data e validade. Uma decisão operacional de planejamento não cria autoridade institucional para gastos, contratos, publicação de dados ou compromissos com terceiros.

**Escalonar** quando houver custo, segurança, publicação externa, direitos de propriedade intelectual, dados pessoais ou impactos entre células. Para decisões arquiteturais, usar um ADR em `docs/08-decisoes/adrs/`.
