# Gestão de solicitações

> **Situação:** Proposto. 

**Pergunta de origem:** pedidos intra/intercelulares serão realizados pela plataforma? A decisão definitiva não foi documentada nas fontes acessíveis.

Fluxo proposto: criar solicitação com identificador → classificar (apoio técnico, dados, equipamento, compra, acesso etc.) → designar célula destinatária → triagem → aceite, negociação ou devolução → execução → validação pelo solicitante → encerramento.

Campos mínimos: título; problema; solicitante; destinatário; data; urgência justificada; dependências; prazo desejado; critérios de atendimento; anexos ou links e trilha de mudanças. Não declarar atendimento pelo simples registro do pedido.
