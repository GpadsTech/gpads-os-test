# Encerramento de entregas

> **Situação:** Proposto, baseado em requisitos confirmados. 

Antes de concluir, conferir: critério de aceite testado; evidência vinculada à versão correta; documentação mínima; revisão registrada; validação registrada; DoD aplicável atendida; dependências resolvidas ou formalmente encaminhadas.

Se reprovado, devolver a execução com justificativa. Não confundir “atividade realizada” com “resultado validado”. Para produtos de hardware, verificar arquivos de fabricação, revisão e registro de teste; para dados/IA, integridade de dados, reprodutibilidade e métricas justificadas.
