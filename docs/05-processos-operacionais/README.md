# Processos operacionais

> **Situação:** Confirmado (necessidades); Proposto (rotinas). 

Esta seção traduz a arquitetura em rotina: entrada de demanda, planejamento e acompanhamento, impedimentos, relatórios quinzenais, solicitações entre células e encerramento de entregas.

Prazos e canais oficiais permanecem pendentes. Onde aparece um fluxo sugerido, ele deve ser avaliado e registrado como decisão antes de se tornar procedimento obrigatório.
