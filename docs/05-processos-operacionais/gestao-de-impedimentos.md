# Gestão de impedimentos

> **Situação:** Proposto. 

Impedimento é obstáculo com impacto real no andamento de uma entrega. Registre item afetado, descrição objetiva, início, impacto, necessidade de ajuda, responsável pelo encaminhamento e data de reavaliação. Diferencie risco potencial de impedimento existente.

Fluxo proposto: identificar → comunicar → encaminhar à célula competente → negociar ação/prazo → acompanhar → registrar solução ou escalonamento. Não apagar o histórico ao resolver.
