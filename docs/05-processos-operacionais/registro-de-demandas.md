# Registro de demandas

> **Situação:** Proposto. 

Para iniciar uma demanda, documentar: identificador, solicitante, célula responsável, problema, resultado esperado, vínculo com produto, urgência justificada, critérios de aceite, dependências e anexo/link. Verificar duplicidade antes de abrir novo item.

**Triagem proposta:** receber → pedir esclarecimento se necessário → classificar → designar responsável → priorizar → vincular à hierarquia de trabalho → acompanhar. Solicitações de compra devem seguir a instância competente; cadastro na plataforma não equivale a autorização.
