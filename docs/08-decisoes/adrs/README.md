# ADRs — registros de decisões arquiteturais

> **Situação:** Proposto. 

Use um arquivo por decisão importante, nomeado `0001-titulo-curto.md`, `0002-titulo-curto.md` etc. Inclua contexto, opções, decisão, justificativa, consequências, responsável, data e estado (proposta, aceita, substituída). Use [`templates/decisao/template-adr.md`](../../../templates/decisao/template-adr.md). Nenhuma decisão de implantação foi inventada para preencher esta pasta.
