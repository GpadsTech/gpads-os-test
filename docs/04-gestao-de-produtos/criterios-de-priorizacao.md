# Critérios de priorização — proposta

> **Situação:** Proposto. 

Priorizar mediante critérios transparentes, sem transformar pontuação arbitrária em decisão automática:

| Critério | Pergunta orientadora |
|---|---|
| Valor científico ou de uso | Qual resultado concreto produz? |
| Urgência e dependência | Desbloqueia outras atividades ou compromisso real? |
| Risco | Reduz incerteza técnica, operacional ou de segurança? |
| Esforço/capacidade | Cabe à equipe com os recursos disponíveis? |
| Alinhamento | Está conectado às prioridades aprovadas? |

Para cada item, anotar justificativa, quem priorizou e quando. Pesos quantitativos, reuniões de priorização e tratamento de exceções são pendentes de aprovação.
