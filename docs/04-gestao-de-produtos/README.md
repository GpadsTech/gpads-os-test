# Gestão de produtos e entregáveis

> **Situação:** Confirmado (hierarquia); Proposto (detalhes). 

O trabalho é organizado na hierarquia **produto/entregável → épico → história → microentrega**, uma decisão recuperada das discussões. O modelo exige critérios de aceitação, vínculos e evidências. Consulte `hierarquia-de-trabalho.md`, `ciclo-de-vida.md`, `gestao-de-backlog.md`, `criterios-de-priorizacao.md`, `criterios-de-aceitacao.md`, `revisao-e-validacao.md` e `rastreabilidade.md`.

Para um novo produto, copie o modelo em [`products/_template-produto`](../../products/_template-produto/README.md).
