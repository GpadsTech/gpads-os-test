# Rastreabilidade de trabalho e evidências

> **Situação:** Proposto. 

Um registro rastreável deve permitir responder: **por que** existe esta entrega, **quem** a executa, **qual** requisito atende, **onde** estão versão e evidências e **quem** revisou/validou.

Vínculos mínimos propostos: produto → épico → história → microentrega → commit/artefato/teste → revisão/validação; célula e membro responsáveis; relatório quinzenal que referencia a atividade. Prefira IDs imutáveis e links persistentes. Não copie arquivos grandes ou dados sensíveis apenas para “provar” a entrega.
