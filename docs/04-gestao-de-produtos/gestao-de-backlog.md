# Gestão de backlog

> **Situação:** Proposto. 

O backlog deve armazenar demandas ainda não comprometidas e seus vínculos com produtos. Antes de planejar uma história, conferir: necessidade, benefício, critério de aceitação, tamanho, dependências e responsável por esclarecer dúvidas.

**Refinamento sugerido:** registrar novos itens → eliminar duplicatas → identificar dependências → estimar esforço com critério explícito → priorizar → selecionar microentregas para a quinzena → reavaliar ao fechar ciclo. A plataforma, quando adotada oficialmente, deverá ser a referência do estado e o Markdown o registro de políticas e artefatos.
