# Padrões e qualidade

> **Situação:** Confirmado (necessidade); Proposto (critérios). 

Os padrões procuram assegurar que as entregas do GPADS sejam legíveis, verificáveis e reproduzíveis. **Definition of Done explícita** foi uma necessidade identificada nas conversas. Este diretório trata políticas propostas; os checklists específicos de domínio ficam em [`standards/`](../../standards/README.md).
