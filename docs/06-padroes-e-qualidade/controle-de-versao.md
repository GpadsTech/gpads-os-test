# Controle de versão

> **Situação:** Proposto. 

Versionar documentos e artefatos por Git sempre que adequado. Usar histórico de mudanças legível; referenciar commits, tags ou revisão de placa/modelo em relatórios e evidências; revisar mudanças antes de incorporá-las à versão principal.

Evitar arquivos binários sem controle de origem e formato; para hardware, guardar revisão do esquema/PCB e arquivos de fabricação que correspondam à mesma revisão. O versionamento efetivo dos repositórios dos produtos deve ser verificado caso a caso.
