# Gestão de evidências

> **Situação:** Proposto. 

Evidências podem incluir commit, teste, dataset versionado, fotografia autorizada, laudo de bancada, relatório experimental ou documento técnico. Para serem úteis, devem informar contexto, versão, método de obtenção, resultado e localização permanente.

Guarde arquivos grandes ou sigilosos em armazenamento próprio com controle de acesso; registre link, ID e hash quando relevante. Uma evidência não é aprovação: ela suporta revisão e validação.
