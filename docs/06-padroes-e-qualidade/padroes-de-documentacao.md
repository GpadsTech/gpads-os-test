# Padrões de documentação

> **Situação:** Proposto. 

Cada documento deve informar propósito, público-alvo, status de aprovação, versão/revisão quando pertinente, pré-requisitos, passos, resultados esperados e responsável por atualização. Use Markdown UTF-8, headings hierárquicos, links relativos e nomes de arquivo em minúsculas com hífens.

Registre fontes e separe fatos confirmados, decisões ratificadas, propostas e pendências. Diagramas podem ser versionados como código quando apropriado; não armazenar imagens sem licença/autorizações adequadas.
