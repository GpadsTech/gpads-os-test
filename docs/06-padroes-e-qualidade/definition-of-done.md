# Definition of Done — orientação

> **Situação:** Confirmado (DoD explícita e revisão); Proposto (itens). 

A **DoD** estabelece condições gerais para chamar um trabalho de concluído. Não substitui os critérios de aceite específicos da história ou microentrega.

**Checklist geral proposto:**
- [ ] Escopo e resultado estão documentados.
- [ ] Critérios de aceitação foram verificados e têm evidências.
- [ ] Código/artefato e documentação têm versão e localização identificáveis.
- [ ] Testes pertinentes foram realizados, com resultados registrados.
- [ ] Revisão técnica/documental foi registrada.
- [ ] Validação do resultado foi registrada.
- [ ] Impedimentos remanescentes foram resolvidos ou encaminhados formalmente.

Consultar [`standards/definition-of-done`](../../standards/definition-of-done/README.md) para variações por domínio. A lista ainda está sujeita a aprovação.
