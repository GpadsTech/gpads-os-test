# Onboarding

> **Situação:** Confirmado (objetivo); Proposto (roteiro). 

O onboarding é orientado a autonomia: um novo membro deve identificar sua célula, responsabilidades, produto, ambiente e manuais necessários para reproduzir uma atividade. Leia `guia-do-novo-integrante.md`, `primeiros-passos.md`, `ferramentas-utilizadas.md`, `acesso-aos-repositorios.md`, `primeiro-relatorio.md` e `checklist-onboarding.md`.
