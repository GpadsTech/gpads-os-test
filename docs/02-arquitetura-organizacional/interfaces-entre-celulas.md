# Interfaces entre células

> **Situação:** Proposto. 

As interfaces representam serviços ou contribuições prestadas de uma célula a outra. Exemplos **ilustrativos**: Hardware solicita suporte de dados; IA Ambiental solicita dados estruturados; Gestão de Entregas pede atualização de progresso; Educação solicita material técnico revisado. Não são solicitações reais.

**Contrato mínimo de demanda proposto:** solicitante; célula destinatária; produto vinculado; descrição; critério de aceite; evidências; prioridade; prazo desejado; responsável pelo retorno; estado e histórico de encaminhamentos.

Encaminhe a implementação ao fluxo em [`workflows/solicitacoes`](../../workflows/solicitacoes/README.md). Questões pendentes: autoridade para priorizar pedidos, acordos de atendimento, registro de compras e canal digital oficial.
