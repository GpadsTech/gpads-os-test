# Relatórios de gestão

> **Situação:** Proposto. 

Esta pasta recebe sínteses agregadas da operação e relatórios para decisões de gestão. **Relatórios individuais pertencem a `cells/`.** Relatórios consolidados da célula permanecem em `cells/<celula>/relatorios/`; a visão geral deve apontar para eles e discutir riscos e resultados agregados.
