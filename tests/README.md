# Testes do repositório

> **Situação:** Implementado. 

Execute `python -m unittest discover -s tests -v` a partir da raiz. Os testes conferem presença dos arquivos, vínculo dos membros, material mínimo dos relatórios e a ausência de relatórios retrospectivos fictícios. A suíte não testa a aplicação Base44 nem garante a correção institucional das políticas propostas.
